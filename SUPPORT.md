# Support

This project is pre-alpha.

## Community Support

Use GitHub issues for:

- Reproducible bugs.
- Documentation gaps.
- Feature requests that fit the roadmap.
- Deployment problems with sanitized logs and configs.

Do not include secrets, access tokens, raw tool payloads, private database rows, or proprietary customer data in issues.

## Security Issues

Use the process in [SECURITY.md](SECURITY.md). Do not file public issues for suspected vulnerabilities.
